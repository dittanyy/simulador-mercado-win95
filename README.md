SIMULADOR DE CONCENTRACIÓN DE MERCADO (ESTÉTICA WINDOWS 95)

ENLACES OFICIALES:
Aplicación Web Operativa: https://dittanyy.github.io/simulador-mercado-win95/

INSTRUCCIONES DE EJECUCIÓN LOCAL:
1. Descomprima este archivo ZIP en cualquier ubicación de su equipo.
2. No requiere la instalación de un servidor backend, Python ni Node.js.
3. Abra el archivo 'index.html' directamente en cualquier navegador web moderno (Chrome, Edge, Firefox, Brave).
4. Nota: Requiere conexión a Internet para la carga inicial de la librería Chart.js v4.4.1 vía CDN.
